## 🧠 Featured Projects

### 1) ReQuery — SLM-Powered Query Rewriting for RAG
[![Repo](https://img.shields.io/badge/GitHub-ReQuery-181717?style=flat-square&logo=github)](https://github.com/HLDKNotFound/ReQuery)

A compact but impactful project focused on improving retrieval performance through query rewriting and expansion using small language models.

- Fine-tuned `Qwen2.5-0.5B-Instruct` with `4-bit QLoRA`
- Built retrieval pipeline with `Sentence Transformers`, `FAISS`, and `RRF`
- Improved `Recall@10` from `0.52` to `0.79`
- Achieved `+62.49% relative MRR@10`
- Increased downstream token F1 by `25.12%`
- Integrated data prep, evaluation, checkpointing, and FastAPI inference

**Tech Stack:** Python, PyTorch, Transformers, PEFT, QLoRA, FAISS, FastAPI

### 2) MovieNex — Movie Recommendation System
[![Repo](https://img.shields.io/badge/GitHub-MovieNex-181717?style=flat-square&logo=github)](https://github.com/dducsw/movie-recsys)

A multi-stage recommendation engine combining retrieval, ranking, and conversational recommendation.

- Candidate generation using `Implicit ALS`, `TF-IDF`, and `Qdrant`
- Learned ranking with `LightGBM LambdaRanker`
- Diversity-aware re-ranking with `MMR`
- Conversational recommendation agent using `LangGraph`
- Natural-language-to-SQL support with PostgreSQL safeguards
- Full-stack app with FastAPI + React + Redis + Docker

**Tech Stack:** Python, LightGBM, Implicit ALS, Qdrant, LangGraph, FastAPI, React, PostgreSQL, Redis, Docker

### 3) AutoML-Agent — LLM-Powered ML Automation
[![Repo](https://img.shields.io/badge/GitHub-AutoML-Agent-181717?style=flat-square&logo=github)](https://github.com/HLDKNotFound/AutoML-Agent)

An LLM-driven workflow that automates model selection, validation, training, and evaluation for tabular data problems.

- Built with `Gemini 2.5 Flash`, `LangChain`, and `LangGraph`
- Automated data validation and quality checks
- Evaluated multiple models across several ML families
- Hyperparameter tuning with `Optuna TPE`
- Developed dataset upload, comparison, and prediction interface

**Tech Stack:** Python, Gemini API, LangChain, LangGraph, scikit-learn, Optuna, FastAPI, React
